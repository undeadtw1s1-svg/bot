Шаг 2. Установка Ngrok (Можете пропустить если уже есть другой https сервер и ссылка на его адрес)

Скачайте и установите ngrok:

Скачайте утилиту с официального сайта ngrok.com или установите через менеджер пакетов (например, winget install ngrok на Windows / brew install ngrok на macOS / snap install ngrok на Linux).

Зарегистрируйте бесплатный аккаунт и подключите токен авторизации:


ngrok config add-authtoken ВАШ_ТОКЕН

Запустите веб-сервер Mini App:
В терминале проекта запустите app.py


uvicorn app:app --host 0.0.0.0 --port 8000

Откройте HTTPS-туннель:

В отдельном окне терминала выполните команду:


ngrok http 8000
В окне появится строка Forwarding, содержащая публичный адрес вида:
https://xxxx-xx-xx-xx.ngrok-free.app

Привяжите URL к проекту:

Скопируйте полученную ссылку (начинающуюся с https://).

Вставьте её в .env в параметр WEBAPP_URL:


WEBAPP_URL=https://xxxx-xx-xx-xx.ngrok-free.app


Запустите бота:

python main.py

7. Логика работы сервиса
Пользователь открывает Mini App, вводит ключевые слова для поиска (например, RTX 5060), список минус-слов (например, ноутбук, ПК, сборка) и сохраняет настройки.

Фоновый воркер каждые 45–60 секунд опрашивает Kufar по активным поисковым запросам.

Каждое найденное объявление проверяется по списку минус-слов и сверяется с таблицей seen_ads в PostgreSQL.

Если объявление новое, бот мгновенно присылает карточку товара в Telegram и заносит ID лота в базу, исключая спам и дубликаты.
